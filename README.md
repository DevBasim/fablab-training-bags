# نظام الحقائب التدريبية – فاب لاب الأحساء

تطبيق عربي RTL لإدارة الحقائب التدريبية بدل العمل المباشر على ملفات Excel.

## الوضع الحالي
- واجهة دخول وإنشاء حساب.
- لوحة رئيسية RTL متجاوبة.
- صفحات: الرئيسية، حقائبي، إنشاء حقيبة، إدارة الحقائب.
- ربط مبدئي مع Supabase Auth وPostgres.
- إنشاء حقيبة وحفظ بياناتها في `training_bags`.

## الخطوات التالية
1. إضافة مفتاح Supabase publishable إلى إعدادات التطبيق.
2. بناء جميع أقسام نموذج الحقيبة حسب قالب Excel المعتمد.
3. إضافة الحفظ التلقائي والعودة لإكمال الحقيبة.
4. إضافة رفع المرفقات إلى Supabase Storage.
5. بناء المخرجات وخطة التنفيذ والموارد والمراجعات.
6. تنفيذ التصدير إلى قالب Excel الأصلي مع الحفاظ على الخلايا والتنسيق.
7. اختبار الصلاحيات وRLS قبل التشغيل الفعلي.
